# Mergen Tanıtım Afişi

Bu klasör, UniS takımının Mergen projesi için teknik sır vermeyen tanıtım afişini içerir.

Dosyalar:

- `mergen_tanitim_afisi.svg`: Düzenlenebilir vektör afiş.
- `mergen_tanitim_afisi.pdf`: Paylaşım ve baskı için PDF çıktı.
- `afis_uret.py`: PDF çıktısını yeniden üretmek için Python scripti.

Afiş; ÖTR, şartname ve güncel yazılım/mekanik çalışma özetlerine göre hazırlanmıştır. Kontrol algoritması, özel mekanik ayrıntılar veya kopyalanabilecek teknik çözüm detayları özellikle verilmemiştir.
