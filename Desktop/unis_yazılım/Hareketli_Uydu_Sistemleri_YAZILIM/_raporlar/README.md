# Raporlar

Bu klasör, yazılım çalışma alanındaki rapor ve şablon dosyalarını düzenli tutmak için ayrılmıştır.

| Klasör | İçerik |
| --- | --- |
| `KTR/` | Kritik Tasarım Raporu şablonları, ekip görev planı ve KTR çalışma dosyaları |
| `OTR/` | Ön Tasarım Raporu ve ÖTR şablonu |
| `Sartname/` | Yarışma şartnamesi |
| `Sunum/` | UniS sunum ve proje raporu PDF çıktıları |
| `Yazilim/` | Yazılım raporları, sistem mimarisi ve çalışma ortamı özetleri |

Kod klasörleri bilinçli olarak taşınmamıştır. `Efe/`, `arayuz/`, `kerim unis/`, `simge_elif/` ve `afis/` klasörleri mevcut yolları bozmamak için yerinde tutulmuştur.
